# From a question to checkable evidence

Open Evidence in the research navigation. Enter a question and working hypothesis. Select papers and record whether each excerpt supports, challenges, or provides context. Add the original page number and a short excerpt. Read the actual source: completeness checks fields, not truth.

One paper may have multiple records. Seek evidence that challenges the hypothesis, then describe the conclusion and its limits. Excerpts are user-recorded; AI responses still require source checks.

Prepare AI review fills the Agent composer. Review it and send it yourself using a configured Agent. It does not automatically send requests or authorize file changes.

Save research note creates a new Markdown file under notes/research in a local desktop vault. Each save creates a separate file without replacing paper NOTES.md; edit saved content in the Markdown editor. Drafts last for the current window session, so save before quitting. This save entry does not yet support remote vaults.
