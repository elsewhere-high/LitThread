# Put the evidence on your desk

The Literature index is the starting point for research in LitThread. Its permanent navigation takes you to the collection, files and search. Every paper has a folder so the source and your interpretation can stay together.

## Collect a first reference

Choose Import PDF in the index, or drop a PDF into the index or file tree. Use Add reference for a DOI, arXiv identifier, paper link or title. LitThread tries to retrieve metadata and available material; sources without an accessible full text may require a PDF you supply.

Existing Zotero material can be migrated from the welcome screen. To use Zotero Connector, enable it in Settings and avoid another local Zotero process using the same interface. The browser extension then saves into the active library.

## Work through the collection

Narrow the list with search, sort and customize columns using the headers, and organize topics with tags. Double-click a row to read; single-click a field to copy it. Organizational folders under papers scope the index. Rescan discovers paper folders already on disk.

Keep the main PDF at the paper folder root. Original TeX belongs in source, parsed text in PAPER.md, and your thinking in NOTES.md. Additional PDFs, code and supplements belong in attachments, created only when needed.

After reading, record the question, method, evidence and remaining uncertainties. Continue with [[02 Agent and Skills]] or [[03 Markdown and Wikilinks]].
