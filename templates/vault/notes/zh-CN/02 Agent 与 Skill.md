# 让对话围绕证据展开

文脉把知识库上下文连接到兼容 ACP 的 Agent。先在“设置 → Agent”中选择或添加程序，并完成该程序需要的安装和登录。工具没有配置时，本地整理、阅读与编辑仍可使用。

## 开始一次有依据的提问

打开论文，再点击左侧“对话”。用 @ 提及材料，也可以从目录拖入文件或把 PDF 选区加入上下文。描述具体问题，例如“请根据当前材料，列出方法成立的假设，并标出对应段落”。

查看 Agent 申请的文件、命令和网络操作，保留审批边界。回复进行中可继续输入，后续消息按队列处理。模型回答需要与引用材料核对，不应直接视为已完成的实验。

## 选用研究技能

技能位于 .agents/skills，可由输入区选择。使用 $ 引用技能，/ 打开可用命令。paper-reader 用于精读，author-lookup 核对公开作者信息，litthread-cli 管理目录与论文，vault-normalizer 整理目录，deep-research 与 idea-evaluator 用于调查和评审。

精读需要可读的论文正文。自动精读默认关闭，可在设置中按需要启用。精读输出进入论文 NOTES.md，已有笔记需要保留。CLI 本身不运行 Agent，也不会自动写出完整研究结论。

新增技能时建立独立目录和 SKILL.md，写明用途与输入输出。不要在技能或知识库中保存 API Key。修改捆绑技能前阅读 `.agents/skills/README.md`。
