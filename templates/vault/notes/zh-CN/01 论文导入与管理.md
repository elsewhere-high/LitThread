# 把资料放上书桌

文脉的“文献索引”是研究的起点。左侧固定导航可随时回到文献、打开目录或进行检索。每篇论文拥有自己的资料文件夹，笔记与原文可以一起保留。

## 收集第一份材料

在索引顶部选择“导入 PDF”，也可以直接把 PDF 拖入索引或目录。已有 DOI、arXiv 编号、论文链接或标题时，选择“添加文献”并输入线索。文脉会尝试获取元数据与可用资源；网络来源没有提供全文时，需要你补充 PDF。

已有 Zotero 资料可以从欢迎页迁移。若使用 Zotero Connector，在设置中启用对应功能并避免本机 Zotero 占用同一接口；通过浏览器扩展保存材料到当前知识库。

## 从索引开始阅读

搜索框用于缩小结果，列标题用于排序和调整展示，标签用于组织主题。双击论文行打开阅读；单击单元格可复制字段。选择 papers 下的组织目录可以查看该范围。扫描功能用于重新发现磁盘上的论文资料。

主论文 PDF 放在论文文件夹根目录。source 保存原始 TeX，PAPER.md 保存解析正文，NOTES.md 保存你的理解。补充材料、代码与额外 PDF 放入 attachments，按需创建目录。

完成一次阅读后，在笔记中记录问题、方法、证据与仍未解决的疑问。继续阅读 [[02 Agent 与 Skill]] 或 [[03 Markdown 与双链]]。
