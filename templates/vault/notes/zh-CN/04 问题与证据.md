# 从问题到可核对的证据

打开左侧“证据”，填写研究问题与工作假设。在文献列表选取来源，为每条记录选择支持、反证或背景，填写原文页码和短摘录。请实际阅读原文；完整度提示只检查字段，不验证论据真假。

同一来源可以有多条记录。寻找挑战假设的材料，再写结论与适用边界。记录由用户录入，AI 回答仍需回到原文核对。

“准备 AI 审查”填入 Agent 输入框，检查后自行发送；需要已配置的 Agent。不会自动发送或授权修改文件。

“保存研究笔记”在本地桌面知识库的 notes/research 中创建新 Markdown 笔记。每次保存都是新文件，不覆盖论文 NOTES.md；修改保存后的内容请使用 Markdown 编辑器。草稿仅在当前窗口内保留，退出前请保存。远程知识库暂不支持此入口的保存。

参见 [[03 Markdown 与双链]] 与 [[02 Agent 与 Skill]]。
