# 让笔记形成文脉

笔记是普通 Markdown 文件。论文内的理解写入 NOTES.md；跨论文的概念写入 notes，研究计划写入 plans。文件可以在文脉或外部编辑器中打开。

## 写下结构

使用标题区分问题、方法、证据与疑问。列表记录要点，引用块保留原话。编辑器中在行首或空格后输入 / 可以插入标题、代码、图表、链接和 Callout；代码块内部不会触发命令菜单。

行内公式使用 $E=mc^2$，独立公式使用成对的 $$。普通美元符号需要转义。Mermaid 使用 mermaid 围栏代码块，Callout 使用 > [!NOTE]、> [!TIP] 等标记。

## 连接已有材料

双链写为 `[[笔记名]]`，显示别名写为 `[[目标|别名]]`，标题锚点写为 `[[笔记名#标题]]`，嵌入使用 `![[目标]]`。输入 [[ 后使用补全选择实际存在的文件。双链区分真实路径，重名材料应补足目录，不编造不存在的引用。

引用图片时用 Markdown 相对路径，将图片放在当前笔记旁的 assets 目录。普通网页用标准 Markdown 链接，保留可核对的来源。

## 保存与维护

外部编辑器同时修改文件时，先核对磁盘版本，再合并自己的内容。重命名或移动资料后检查双链；删除前确认没有仍在使用的材料。复杂整理可配合 vault-normalizer 的诊断，保留原文与用户批注。
