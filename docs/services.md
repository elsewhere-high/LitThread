# 可选服务配置

文脉的默认入口不绑定公共模型网关、远程中继、分析账号、自动更新或 CLI 发行仓库。缺少可选配置时，本地阅读与编辑仍可使用，对应联网能力会提示配置或不可用。

| 能力 | 配置位置 | 未配置时 |
| --- | --- | --- |
| Agent | 设置 → Agent，兼容 ACP 的可执行程序与其登录配置 | 无研究模型会话 |
| 文献格式转换 | 设置 → 通用 → 文献格式转换服务，自己的 Zotero Translator 地址 | BibTeX/RIS 等转换不可用 |
| 翻译 | 设置 → 翻译，选择提供者及所需端点、模型和凭据 | 该提供者不可用 |
| 版面解析 | 设置 → 版面解析，模型与计算方式 | 按当前可用解析方式运行 |
| 远程设备 | 设置 → 远程访问，实际中继或直连配置 | 不自动连接中继 |
| SSH 知识库 | 欢迎页 → 打开远程，实际主机与资料路径 | 不建立 SSH 会话 |
| 同步 | 设置 → 同步，自己的同步服务配置 | 不同步资料 |
| 应用更新 | Tauri updater 的 endpoint 与公钥 | 不查询自动更新 |
| CLI 在线安装 | 构建变量 `LITTHREAD_RELEASE_REPO=owner/repository` | 仅本地已构建 CLI 可用 |

`.env.example` 列出构建时可选变量。`LITTHREAD_BUILTIN_BASE_URL` 与 `LITTHREAD_BUILTIN_API_KEY` 必须同时存在才启用内置提供者；构建时值会进入原生二进制，个人凭据应优先通过应用的运行时配置提供。不要把真实 `.env`、证书、令牌或用户资料提交到 Git。

分析默认关闭，分析 key 为空。不要在没有实际维护服务的情况下填写占位 endpoint。第三方论文元数据和资源可能访问 Crossref、OpenAlex、arXiv 等公开服务；这些属于业务来源，受其可用性与请求限制影响。

学术 API 联系信息由启动进程的 `LITTHREAD_CONTACT_EMAIL` 提供，未填写时不冒用邮箱。必须有邮箱的 Unpaywall 查询会跳过。示例文件不会自动设置进程的运行时环境变量。

不同提供者的配置与外部程序认证互相独立。排查时先在相应设置页确认可执行文件、模型和端点，再测试一次明确、无敏感内容的请求。设备配对需核对两端验证码；保持现有连接和 Agent 的审批规则。
