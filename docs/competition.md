## 项目定位与本轮贡献

LitThread · 文脉服务个人文献研究。把研究问题、假设、支持证据、反证与结论连接在同一工作台，研究记录以普通 Markdown 保存在用户知识库，AI 参与审查而不替代原文核对。

## 建议演示流程

1. 在独立演示知识库导入两份可合法展示的文献，展示索引与阅读。
2. 提出一个可以核对的问题，填写假设，录入支持与反证，每条附页码和短摘录。
3. 展示完整度提示，说明“记录完整”不等于“结论正确”。
4. 准备 AI 审查，展示待发送提示词；配置真实 Agent 后再录制实际回答，核对模型引用。
5. 写下结论边界，保存研究笔记，打开论文双链，再用外部编辑器读取 Markdown。
6. 展示未更改字段的 YAML 注释保留，以及关闭证据标签页后草稿恢复。

演示生成器的 PDF 与笔记属于测试材料，不能作为真实论文论据。没有实际完成的 Agent 调用、真机连接、远程同步或实验不能在视频或介绍中宣称已验证。
