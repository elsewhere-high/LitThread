# 在文脉里开展研究

## 先确定资料位置

欢迎页提供建立知识库、打开已有目录、SSH 连接和 Zotero 迁移。建立知识库会补齐缺失的结构和入门笔记，不覆盖同名用户文件。知识库可以有多个；欢迎页记录最近打开的位置。

建议为一个研究方向建立一个知识库。`papers/` 保存论文材料，`notes/` 保存概念与跨论文笔记，`plans/` 保存研究计划。应用内部索引位于 `.litthread/`，不要把它当作笔记修改。

## 让材料进入索引

左侧“文献”打开文献索引。在顶部导入本地 PDF，或通过“添加文献”输入标题、DOI、arXiv 编号和可识别链接。PDF 也可以拖入文件目录或索引区域。网络导入可能受来源限制；缺少 PDF 的条目仍可保留元数据。

索引搜索支持标题、作者等字段；列标题用于排序和列设置，标签列提供筛选。双击论文行进入阅读，单击可复制对应字段。目录中的组织文件夹可以限定索引范围。若文件存在但未入库，可使用重新扫描。

## 从阅读到笔记

PDF 阅读器提供缩放、检索、文本选择和批注。侧栏可展示引用、标注与相关信息。选中文本后可以创建批注、翻译或将材料交给 Agent；后两者需要先设置相应工具。

每篇论文的工作笔记是 `NOTES.md`，解析后的正文是 `PAPER.md`。二者用途不同：前者属于你的理解，后者来自原始材料。附件放在论文目录的 `attachments/`，TeX 原文放在 `source/`。

Markdown 支持公式、Mermaid、Callout、`[[双链]]` 和 `![[嵌入]]`。编辑器中的 `/` 打开插入菜单。文件被外部编辑器同时修改时，文脉会提示冲突并保护未保存内容；先核对磁盘版本再合并。

## 用证据回答问题

左侧“证据”打开证据工作台。写下研究问题和工作假设，点击“添加文献”，为每条记录选择支持、反证或背景，填写原文页码与摘录。同一论文可以记录多条证据；来源数按完整记录的论文目录去重。缺少页码或摘录的条目不计入完整记录。

工作台提示是否需要补充证据、寻找反证或准备审查，这些提示不代表结论已被验证。摘录来自你的录入，需要回到原文核对。点击文献卡片的阅读按钮可以打开对应材料。

“准备 AI 审查”把问题、证据和核对要求放入已有 Agent 输入框。检查后再发送；运行 Agent 仍需要相应配置，并遵守原有权限确认。

“保存研究笔记”在本地桌面知识库的 `notes/research/` 中创建独立 Markdown 文件，保留指向论文笔记的双链。每次保存生成新文件，后续内容可在 Markdown 编辑器修改；此版本不把已保存笔记重新载入工作台。草稿按知识库隔离，在当前窗口内保留；退出应用前请保存。远程知识库暂不支持此入口的保存。

## 围绕材料对话

在设置的 Agent 页选择或添加兼容 ACP 的程序，按该程序要求安装和登录。模型功能需要你配置的服务；文脉不预置可直接使用的公共模型凭据。

左侧“对话”打开研究面板。可用 `@` 提及资料、将选区加入上下文、通过技能选择器引用技能。涉及文件或命令操作时保留应用的权限确认。没有设置 Agent 时仍可使用本地阅读和编辑。

## 继续发现与携带

“发现”汇集论文来源、RSS、研究技能和 arXiv 推荐。外部来源依赖网络；默认入口页只列出来源，打开具体来源后才进行对应访问。

移动端是桌面知识库的配对客户端。先在桌面“远程访问”中配置连接方式，再扫描配对码并核对验证码。SSH 知识库与设备配对是不同连接入口，详情见[可选服务](services.md)。
